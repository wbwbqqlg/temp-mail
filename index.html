📖 FLAI 注册步骤（跟着做，一次过）

第 1 步：获取邮箱

  1. 上方 Tab 默认在 SmailPro（成功率最高）
  2. 等页面加载完 → 点 SmailPro 里的「Generate」按钮
  3. 得到一个邮箱地址（看起来像 Gmail/Outlook，很真实）
  4. 点「复制」或长按选中复制

第 2 步：去 FLAI 注册

  1. 切到 FLAI App → 邮箱注册 → 粘贴刚复制的地址
  2. 点「发送验证码」→ 立刻切回本页面
  3. 回 SmailPro 的 iframe 里等 10~60 秒
  4. 验证码出现在收件箱 → 复制

第 3 步：完成 FLAI 注册

  1. 切回 FLAI → 粘贴 6 位验证码
  2. 密码用：Flai2025@Love（必须含大+小+数+符号）
  3. 完成！🎉

⚠️ SmailPro 收不到？按顺序换

  1. 点 Tab 2：NiMail → 国内直连最快
  2. 点 Tab 3：Guerrilla → 选 @sharklasers.com 域名

💡 为什么这个页面能收到

之前你那个页面用 fetch 直连 Mail.tm / 1secmail API → 被 Cloudflare 拦 + FLAI 拒发 DEA 域。

这个页面改成 iframe 内嵌真实网页版：

  1. ✅ 不调任何 API，不触发 CORS / Cloudflare Bot
  2. ✅ 用服务商自己的网页界面收信，和真人用一样
  3. ✅ SmailPro 生成的是 Gmail 壳地址，FLAI 识别不了是临时的
  4. ✅ NiMail 国内节点，手机不用代理直连
