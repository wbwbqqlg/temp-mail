🚀 方法一：自动轮换模式（强烈推荐）

  1. 点「▶️ 启动自动模式」→ 自动创建 5 个不同域名的邮箱
  2. 页面会每 15 秒自动切换显示下一个邮箱地址
  3. 打开 FLAI App → 注册 → 邮箱栏粘贴当前显示的地址
  4. 点「发送验证码」→ 立刻切回本页面
  5. 如果 30 秒没收到 → 等页面自动切到下一个邮箱 → 再去 FLAI 换邮箱重试
  6. 哪个邮箱先收到验证码 → 自动弹出！验证码高亮可复制
  7. 也可以同时把 5 个邮箱都复制到 FLAI 轮流试（点列表里的「复制」）

📝 方法二：手动模式

  1. 在上方选择一个域名（带 [GW] 的优先）
  2. 点「生成」→ 邮箱地址出现 → 点「复制」
  3. 打开 FLAI App → 注册 → 粘贴邮箱 → 点发送验证码
  4. 立刻切回本页面（保持前台）→ 等待 10~60 秒
  5. 邮件到达后 → 6位混合验证码自动高亮 → 复制
  6. 收不到就「销毁」→ 换域 → 重新生成

⚡ 密码格式要求

FLAI 密码必须同时包含：大写字母 + 小写字母 + 数字 + 符号
示例：Flai2025@Love 或 AiChat#6688

🔧 收不到验证码？按这个顺序排查

  1. 换域名：下拉框选另一个域 → 销毁 → 重新生成 → 重试（最重要）
  2. 检查地址：确认 FLAI 输入框里的邮箱和本页显示的完全一致（无空格）
  3. 只点一次发送：连点会触发 FLAI 限速，等 5 分钟再试
  4. 保持前台：切走会暂停刷新，回来等 3 秒自动补刷
  5. 等够 90 秒：FLAI 服务器偶尔延迟，别 10 秒就放弃
  6. 换网络：Wi-Fi ↔ 4G/5G 切换（IP 变了可能就过了）
  7. 终极方案：FLAI 官方不建议临时邮箱，直接用 QQ / 163 / Gmail 注册最稳

📊 如何判断是被拒发还是只是慢？

  • 本页诊断面板「已等待」超过 3 分钟 仍 0 封 → 大概率被拒发 → 换域
  • 超过 5 分钟 → 几乎可以确定被拒 → 换域 or 换真实邮箱
  • 状态显示「API 离线」→ 你的网络连不上 mail.tm → 开 VPN/代理
