# 限时一次性临时邮箱 (Temp Mail)

> 即时生成 · 自动销毁 · 保护你的真实邮箱远离垃圾邮件

一个纯前端、零后端的限时一次性临时邮箱网站，基于 [Mail.tm](https://mail.tm) 公共 API 构建。

## ✨ 功能特性

- **一键生成** — 点击按钮即时创建随机邮箱地址
- **限时销毁** — 支持 5/10/30/60 分钟有效期，到期自动清除
- **实时收件** — 每 8 秒自动轮询新邮件
- **验证码提取** — 自动识别并高亮显示验证码
- **一键复制** — 邮箱地址和验证码均可一键复制
- **手动销毁** — 随时可手动删除邮箱及所有邮件
- **深色 UI** — 现代化暗色主题，响应式适配移动端
- **零后端** — 纯静态 HTML，可部署到任意静态托管

## 🚀 本地使用

直接双击 `index.html` 即可在浏览器中使用（需联网）。

或启动本地服务器：
```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 🌐 部署到 GitHub Pages

### 方法一：自动部署（推荐）

1. Fork 本仓库或创建新仓库，将文件推送到 `main` 分支
2. 进入仓库 **Settings → Pages**
3. **Source** 选择 `GitHub Actions`
4. 推送代码后，GitHub Actions 会自动部署
5. 访问 `https://<用户名>.github.io/<仓库名>/`

### 方法二：手动部署

1. 进入仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选择 `main`，目录选 `/ (root)`
4. 保存后即可访问

## ⚠️ 注意事项

- 本服务依赖 [Mail.tm](https://mail.tm) 免费公共 API，仅供学习和个人使用
- 请勿用于重要账户注册或敏感操作
- 邮箱有效期结束后数据不可恢复
- API 请求频率限制约 8 QPS

## 📄 技术说明

| 项目 | 说明 |
|------|------|
| 前端 | 纯 HTML + CSS + Vanilla JS（无框架依赖）|
| API | Mail.tm REST API |
| 存储 | 仅浏览器内存，无持久化 |
| 部署 | GitHub Pages（GitHub Actions 自动部署）|

## 🔒 隐私声明

- 不收集任何用户个人信息
- 不存储邮件内容到本地
- 所有数据仅存于 Mail.tm 服务器，受限于其隐私政策
- 邮箱过期后通过 API 删除账户
